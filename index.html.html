🔒 Protection des données personnelles

Cette application est un outil pédagogique développé pour un usage en classe.

  • Aucune donnée n'est transmise à un serveur externe : toutes les informations restent uniquement dans la mémoire de votre navigateur, le temps de la partie en cours.
  • Aucun cookie tiers, aucun traceur publicitaire, aucun appel à une API externe n'est utilisé.
  • Les seules données saisies sont : les deux premières lettres de votre prénom et de votre nom, utilisées uniquement pour générer un identifiant au format XX-YY, sans jamais collecter votre identité complète.
  • Ces données ne sont jamais sauvegardées : elles disparaissent automatiquement si vous rechargez ou fermez la page.
